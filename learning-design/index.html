Grade 7 English: Reading comprehension

LESSON DESIGN · VILTGRADE 7 · ENGLISH

Identifying problem and solution

The learning experience is organised around a specific learning outcome: learners identify the problem and solution presented in an informational text.

AudienceGrade 7 learners
Learning focusReading comprehension
Design componentsLesson sequence, guided practice, activities, assessment

What this project demonstrates

  • Outcome-led design. The learning objective establishes what learners should be able to identify.
  • Structured learning. Content and activities are organised to help learners work towards the objective.
  • Practice and assessment. Activities provide opportunities to apply the concept and demonstrate understanding.
  • Digital learning design. The VILT interface supports lesson delivery and learning activities.

The lesson and VILT files will be added to the portfolio assets when the artefacts are ready for publication. These links intentionally point to planned paths.
