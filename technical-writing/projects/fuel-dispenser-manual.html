TECHNICAL WRITING / CASE STUDY

Fuel Dispenser User Manual

A sample user manual created for an interview assignment in 2012, structured around routine operation and user safety.

← Back to Technical Writing

Artefact7-page user manual
AudienceStation operators and customers
PurposeExplain use and routine safety

Context and scope

The manual covers the use of a fuel dispenser at a service station. It introduces the equipment, describes the dispensing process, and addresses safety and daily operating routines. Installation, maintenance, and repair are identified as work for authorised technicians and are not treated as user tasks.

Information structure

The document moves from orientation to action: readers first encounter an introduction and system overview, then instructions for using the dispenser, followed by safety guidance and daily operational routines.

  1. Purpose and introduction
  2. System overview
  3. Using the dispenser and filling positions
  4. Fuel-dispensing steps
  5. Attendant safety instructions
  6. Accident scenarios on the forecourt
  7. Start-of-day, during-operation, and closing routines

Documentation observations

Procedures follow the task

The main operating section is organised as a sequence of actions. This supports readers who need to perform a task rather than read an abstract description of the equipment.

Safety content is part of the operating context

The sample includes attendant safety guidance and scenarios such as a vehicle driving away while the nozzle remains in the tank, or a vehicle colliding with equipment on the forecourt.

Audience boundaries are explicit

The document distinguishes use by station operators and customers from installation or repair activities intended for authorised technicians. That boundary helps keep the user manual focused on its intended purpose.

Portfolio note

This is a historical sample, not a claim that the manual is current product documentation or that it has been usability-tested. The source artefact will be included as a PDF when assets are consolidated.
