Practice becomes more engaging when feedback matters.

FEATURED EXPERIMENT

German learning game

A Pac-Man-inspired maze concept for practising German vocabulary and grammar through short, movement-linked questions.

INTERACTIVE LEARNING · GAME PROTOTYPEGERMAN · HOCHDEUTSCH

Turn a grammar checkpoint into a learning moment

The concept connects learner movement with question checkpoints. Correct answers allow progress; incorrect answers keep the learner in place and provide feedback so the question can be attempted again.

Learning focusGerman vocabulary and grammar
InteractionMovement checkpoints and question responses
FeedbackCorrect-answer celebration and corrective feedback

Design principles

  • Learning integrated with action. Questions appear as part of the game loop rather than in a separate quiz screen.
  • Consequences are understandable. A correct answer advances the player; an incorrect answer preserves the current position.
  • Feedback supports learning. Explanations are intended to clarify the grammar point within the game.
  • Practice variety. A shuffled question bank helps avoid repeating questions in the same sequence.
